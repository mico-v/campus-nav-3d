# 项目侧的 agent 配置

这个目录存放 campus-nav-3d 的「项目人格 + 项目记忆」，与任何个人助理的人格记忆隔离：
读它的人（或 NPC）只关心这个项目，不继承其他上下文。

## 三个文件

- `persona.md`：项目管家的身份、职责与边界。人格只此一份，改这里就是改人格。
- `memory.md`：项目记忆台账。里程碑、已定决策、已知坑、进行中的人与事、未决问题。
- `pipeline.md`：协作工艺（切片模板、门禁三色、PR 纪律），与 `docs/design-overview-v2.md` 第 10 章互为索引。

## 怎么用

在 Issue / PR 评论里 `@` 对应角色（角色定义在 `.cnb/settings.yml`）：

```text
@mico-v/campus-nav-3d(项目管家) 现在到哪一步了？
@mico-v/campus-nav-3d(切片工) 把「室内楼层剖切」拆成切片
@mico-v/campus-nav-3d(审查员) 审一下这个 PR
@mico-v/campus-nav-3d(建模员) 图书馆模型的面数与楼层对得上吗
```

## 记忆怎么更新

- 记忆台账由项目管家维护，规则写在 `memory.md` 末节「更新规则」。
- 每个合并的 PR、每个新决策，各追加一行，带日期与 PR 编号；不覆盖历史，不做大段改写。
- 只在事实变了的时候改；推测、计划中的事进「未决问题」，不进「已定决策」。

## 匿名要求

本仓是公开仓库。人格与记忆里一律不写真实姓名、学号、联系方式、办公室与机房编号，
只写平台账号名（`mico-v` 等）与角色分工（负责人 / 数据建模 / 前端可视化 / 测试文档）。
